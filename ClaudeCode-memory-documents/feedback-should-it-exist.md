**Rule:** before fixing, tuning or measuring a thing, ask whether it should exist at
all. A distinction worth 1% is a deletion, not a choice. And: **one figure per lesson**
— a card or row carries the one number that teaches its point.

**Why:** Kevin, on ruling 2 (4-on-4 in "level" play): *"Is this a situation where we are
optimizing something that shouldn't even be there? … we're great at optimizing, but
less so at deciding if that thing should actually exist."* The measurement I ran
(4-on-4 = 1.1% of attempts) was the evidence the distinction should be deleted, not
the input to picking a winner. On the shift card he chose to drop the under-a-minute
share: "one figure per lesson is a good approach" — but kept "about 21 shifts a night"
because it is a different fact that "tells a story for the novice".

**How to apply:** for every ruling or fix, list each thing it touches with the one job
only it does; anything with no answer is deleted (code, data, tests), not set aside.
Present "should it exist?" before "how to fix it". Removing a second definition counts
as the fix. Keep a thing that is a test's independent witness even when unpublished
([[measures-list]] ruling 6). A distinct fact is not a second figure for the same lesson.
